# CrowKit v0.2.0

小鸦工具箱首个 CrowKit 品牌版本。

## 更新内容

- 产品名称统一为 CrowKit，中文名为“小鸦工具箱”。
- 新增 CrowKit 应用图标、安装器图标和网站资源。
- 官方插件改为随主安装程序分发，不再依赖独立插件仓库或在线插件索引。
- 小鸦刷课、教务抢课和校园网认证随安装包提供，升级主程序时自动同步。
- 插件管理保留 zip 本地安装，并区分随包插件和第三方插件。
- 用户数据目录迁移为 `%LOCALAPPDATA%\CrowKit`。
- GlitchTip 项目名称和 slug 更新为 `crowkit`，错误上报链路已完成验证。
- GitHub 仓库迁移为 `bntool/CrowKit`，介绍页迁移为 `bntool.github.io`。

## 系统要求

- Windows 11 x64
- Microsoft Edge
