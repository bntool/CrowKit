# CrowKit v0.2.1

本次版本新增“自动评教”插件，并完善插件缓存与运行界面。

## 新增自动评教

- 登录北师大评教系统，自动处理期末学生评教问卷。
- 全部量表题统一选择“完全符合”，两道主观题保持留空。
- 按账号持久化待评课程的评教页面地址，缓存非空时直接复用，不再重复抓取。
- 每完成一门课程就从本地缓存中删除对应地址；缓存为空后才重新抓取。
- 配置界面提供“清除课程列表缓存”按钮，并提示新学期新评教先清除旧缓存。
- 默认使用 5 个无头浏览器并行评教，可在 1～10 之间调整。
- 某门课程失败不会阻塞其他课程，失败课程最多重试 3 次。
- 运行页以课程为节点展示进度，并显示并行浏览器面板和当前评教课程。
- 常见登录、网络和账号错误会给出明确提示，未知页面结构或脚本异常会尝试上报 GlitchTip。

## 其他改进

- 配置表单支持显示布尔、数字、选项和文本字段的说明文字。
- 运行页多节点任务改为卡片网格分行展示，避免长流程只能横向滚动。
- README 与官网同步加入自动评教插件介绍。

## 系统要求

- Windows 11 x64
- Microsoft Edge
