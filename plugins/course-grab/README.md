# CrowKit 教务抢课

CrowKit 的教务抢课插件。插件内置专业目录，选择专业后按需抓取课程内容。
课程按代码聚合，可选择整门课程或指定班级，并按课程名、教师、类别和上课时间筛选。
已选课程可拖拽调整轮询顺序。整门课程会合并为一条，同课程多个班级作为择一候选；
任一班提交成功即视为该课程完成，不同课程则要求全部选到。时间冲突只在不同课程
之间检查，并自动考虑候选班级的可选组合。存在冲突时仍可启动：按列表顺序优先尝试，
成功选课后自动跳过与已选班级无法兼容的待选课程。逐个选齐某门课程的全部班级时也会
合并为一条，并可从已选列表删除该课程的全部班级。
账号管理中选择的专业会自动回填到抢课配置；单班级课程会直接展开完整排课信息。
课程列表每页展示 10 门课程，不超过三个班级的课程默认展开。
插件支持轮询余量和自动提交。账号在
CrowKit 的“账号管理”中统一维护，并在插件页选择当前使用的账号。

本仓库只发布插件源码及 Release 安装包。插件配置、缓存和日志保存在
`%LOCALAPPDATA%\CrowKit\plugins\course-grab`。

依赖 CrowKit 0.1.1 或更高版本。可在 CrowKit 的插件管理页面直接安装或更新。
