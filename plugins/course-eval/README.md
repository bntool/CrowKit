# CrowKit 自动评教

CrowKit 的北师大期末学生评教插件。插件使用宿主机中选择的统一身份认证账号登录评教系统，
按账号缓存待评课程的评教页面地址，并使用多个无头浏览器并行完成问卷。

## 使用前注意

如果有不想打好评的课程，请先手动完成评教后再启动此脚本。插件只会处理仍处于“待评教”状态的
课程，已经在学校系统中完成评教的课程会自动跳过。

评教结果由学校系统保存，正式运行前请确认。

## 使用方式

1. 在 CrowKit 的“账号管理”中配置并选择统一身份认证账号。
2. 打开“自动评教”插件，设置并行浏览器数（默认 5，最大 10）。
3. 建议先手动检查课程列表，确认需要评教的课程范围。
4. 点击运行。插件会优先读取当前账号的本地课程地址缓存；缓存为空时才重新抓取。

## 并行评教

- 仅支持无头模式，默认同时启动 5 个无头 Edge 浏览器。
- 每门课程独立交给一个工作浏览器处理，提交后由主进程核对课程列表。
- 运行页会显示并行进程面板，可查看每个浏览器当前正在评教的课程。
- 任务流程仍以课程为节点，多门课程同时进行时会显示多个进行中节点。
- 单门课程提交后固定等待最多 60 秒确认结果，失败时最多重试 3 次。
- 某门课程失败不会阻塞其他课程继续评教；全部结束后会汇总失败课程。

## 课程地址缓存

- 课程地址缓存与账号关联，保存在插件数据目录的 `session.json` 中。
- 获取过一次课程地址后会自动保存，下次启动直接读取，不再重复抓取。
- 每完成一门课程，就会从缓存中删除对应地址。
- 缓存为空时才会重新抓取待评课程地址。
- 配置界面的“清除课程列表缓存”按钮可以手动清空当前账号的课程地址缓存。
- **新学期新评教请清除旧缓存**，否则插件会优先使用上学期保存的课程地址。

当前账号 Cookie 也会记录在同一个缓存文件中，仅保存在本机，不写入日志、不上传。

## 错误处理

- 登录失效、校园网超时、账号密码错误等常见错误会给出明确提示。
- 页面结构变化、未知脚本异常等非预期错误会尝试上报到 GlitchTip。
- 单门课程失败会保留在本地缓存中，方便下次继续处理。

插件日志位于 `%LOCALAPPDATA%\CrowKit\logs\plugins\course-eval.log`。
